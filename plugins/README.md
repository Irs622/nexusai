# 🔌 NexusAI Plugins Directory

This directory hosts officially maintained and community tool plugin packages for **NexusAI**.

---

## 📂 Planned Plugin Ecosystem

```
plugins/
├── README.md                  # Plugin directory guide
├── filesystem/                # Extended local file system tools
├── terminal/                  # Terminal command execution tools
├── macos/                     # Native macOS AppleScript & window tools
├── openai/                    # OpenAI provider adapter
└── ollama/                    # Ollama local model provider adapter
```

For guidelines on creating a custom plugin, see the **[Plugin SDK Guide](../docs/reference/sdk-guide.md)**.
