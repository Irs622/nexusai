# 💬 Getting Support for NexusAI

Thank you for using **NexusAI**! We offer several community support channels depending on your inquiry type.

---

## 📌 Support Channels

| Support Type | Recommended Channel | Details |
| :--- | :--- | :--- |
| **Questions & Discussions** | [GitHub Discussions](https://github.com/Irs622/nexusai/discussions) | Ask general questions, showcase plugins, or share architecture ideas. |
| **Bug Reports** | [GitHub Issues](https://github.com/Irs622/nexusai/issues/new?template=bug_report.md) | Submit reproducible bug reports using our issue template. |
| **Feature Requests** | [GitHub Issues](https://github.com/Irs622/nexusai/issues/new?template=feature_request.md) | Propose new capabilities or architecture enhancements. |
| **Security Vulnerabilities** | [Private Disclosure](SECURITY.md) | See `SECURITY.md` for responsible vulnerability reporting SLA. |

## ❓ Frequently Asked Support Questions

### Where should I start if I want to contribute code?
Start by reading [`CONTRIBUTING.md`](CONTRIBUTING.md) and exploring the [`examples/`](examples/) directory.

### How do I run the full master quality gate locally?
Run `make quality-gate` or `python -m tools.run_quality_gate`.

### Does NexusAI require paid API keys?
No! NexusAI supports local offline LLM engines like Ollama (`http://localhost:11434`) out of the box.
