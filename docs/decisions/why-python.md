# Why Python?

## Decision Rationale
Python is chosen as the primary language for NexusAI because:
1. **Rich AI/ML Ecosystem**: Universal standard for LLM SDKs, Pydantic, and LangChain ecosystem.
2. **Developer Accessibility**: Enables open-source contributors to build plugins quickly.
3. **Async Support**: Native `asyncio` support allows efficient concurrent IO dispatching.
