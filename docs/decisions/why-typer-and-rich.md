# Why Typer & Rich?

## Decision Rationale
1. **Type-Safe CLI**: `Typer` leverages Python type hints for CLI parameter parsing.
2. **Beautiful Terminal UX**: `Rich` provides modern formatting, spinners, tables, and colored logs for a hacker-OS feel.
